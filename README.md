## 🛠️ Getting Started

### Prerequisites

- Node.js (v14 or higher recommended)
- Yarn or npm

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/robertsbaer/react-clock-neumorphic.git
    cd react-clock-neumorphic
    ```

2.  **Install dependencies:**
    ```bash
    yarn install
    # or
    npm install
    ```

3.  **Start the development server:**
    ```bash
    yarn start
    # or
    npm start
    ```

4.  **Open in your browser:**
    Visit [http://localhost:3000](http://localhost:3000)

## 📦 Usage

You can embed the clock component in your own React app:

```jsx
import AnalogClock from './AnalogClock'; // Adjust the path if necessary

function App() {
  return (
    <div>
      <AnalogClock />
    </div>
  );
}
export default App;
```
